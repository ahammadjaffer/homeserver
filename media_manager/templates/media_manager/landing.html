DESKTOP MOUNT INTEGRATION GUIDE

Mount NitroStream as a Native Drive (Z:)

Connect directly from Windows File Explorer, macOS Finder, or Linux using standard WebDAV credentials.

Fast Command (PowerShell / Command Prompt):
net use Z: http://{{ request.get_host }}/webdav /user:your_username your_password
Or via File Explorer GUI:
  1. Open File Explorer → Right-click This PC → Click Map network drive.
  2. Select Drive Letter Z: (or any available letter).
  3. In Folder enter: http://{{ request.get_host }}/webdav/
  4. Check "Connect using different credentials" and enter your NitroStream username and password.
Connect via Finder:
http://{{ request.get_host }}/webdav/
  1. Open Finder → Press Cmd + K (or click Go → Connect to Server).
  2. Enter Server Address: http://{{ request.get_host }}/webdav/ and click Connect.
  3. Choose Registered User and enter your NitroStream username and password.
Mount via davfs2:
sudo mount -t davfs http://{{ request.get_host }}/webdav/ /mnt/nitrostream
  1. Install davfs2: sudo apt install davfs2
  2. Create mountpoint: sudo mkdir -p /mnt/nitrostream
  3. Mount with the command above and enter your credentials when prompted.
