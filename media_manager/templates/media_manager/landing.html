Built Like Commercial Cloud. Hosted at Home.

NitroStream combines the intuitive interface of Google Drive and MEGA with local network gigabit bandwidth and GPU transcoding.

Cloud File Manager SPA
Unlimited nested folder subtrees, breadcrumb navigation, interactive sidebar trees, real-time gallery search, and grid/list view toggling.
Granular Account Sharing
Share files or folder subtrees with specific NitroStream accounts via username autocomplete search, or open access via 128-bit UUID link.
Subtree Security & Boundary Lock
Strict recursive parent-chain validation prevents folder escaping. Shared recipients get read-only access without mutation rights.
GPU NVENC Video Transcoding
Asynchronously transcode heavy MKV files to web-optimized MP4 using NVIDIA GPU acceleration, plus automated HEIC photo conversion.
Protected Nginx Media Streaming
High-performance zero-copy byte streaming powered by Nginx X-Accel-Redirect sendfile offloading after authorization checks.
Mobile Drawer & Quick Upload FAB
Off-canvas collapsible sidebar drawer with topbar hamburger button (`☰`) and fixed red floating action upload button (`+` FAB).
