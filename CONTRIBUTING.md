# Contributing to NitroStream 🚀

Thank you for helping build NitroStream! 

## 🔄 Pull Request Workflow

1. **Fork the Repository**: Create a personal fork on GitHub.
2. **Create a Feature Branch**: `git checkout -b feat/your-feature-name`
3. **Commit Your Changes**: Follow clear commit messages (`feat: ...`, `fix: ...`).
4. **Push to Your Fork**: `git push origin feat/your-feature-name`
5. **Open a Pull Request**: Submit a PR targeting the `main` branch.

*Note: Direct pushes to `main` are restricted. All code changes require maintainer review and approval before merging.*

## 🛠️ Code Conventions
- Follow standard **PEP 8** style for Python backend code.
- Ensure all media streaming endpoints respect user isolation and `is_descendant_of` security checks.
