2. SETUP & STEPS FOLLOWED
--------------------------------------------------------------------------------

[ STEP A: Django & Waitress Configuration ]
  1. Updated `run.py` in the project root to explicitly load `.env` variables 
     and launch Waitress.
  2. Configured Waitress settings in `run.py`:
     - host: '127.0.0.1' (Internal binding for Nginx)
     - port: 8000
     - threads: 8
     - max_request_body_size: 10737418240 (10 GB upload limit)

[ STEP B: Nginx Installation & Setup ]
  1. Downloaded Nginx for Windows (Mainline/Stable) from nginx.org.
  2. Extracted files directly to `C:\nginx\` (ensuring `C:\nginx\nginx.exe` exists).
  3. Replaced contents of `C:\nginx\conf\nginx.conf` with optimized configuration:
     - Enabled zero-copy file streaming (`sendfile on`).
     - Set client body upload limit to 10000M.
     - Added direct static/media aliases pointing to:
       * Media : D:/projects/homeserver/homeserver/media/
       * Static: D:/projects/homeserver/homeserver/staticfiles/
     - Configured reverse proxy (`proxy_pass http://127.0.0.1:8000`) for non-static routes.

[ STEP C: Windows Defender Firewall Configuration ]
  1. Opened Windows Defender Firewall with Advanced Security (`wf.msc`).
  2. Created a New Inbound Rule:
     - Rule Type    : Port
     - Protocol     : TCP
     - Local Port   : 80
     - Action       : Allow the connection
     - Profile      : Private
     - Name         : Nginx Home Server (Port 80)

[ STEP E: Media Manager & Granular Sharing Architecture ]
  1. Built Single Page Application (SPA) Media Manager (`media_manager` app).
  2. Database Models:
     - Folder: name, parent (self-ref for recursive subtrees), owner, share_mode ('private'|'restricted'|'link'), shared_users (m2m), share_token (UUID4).
     - MediaFile: filename, file_size, mime_type, folder, owner, share_mode ('private'|'restricted'|'link'), shared_users (m2m), share_token (UUID4).
  3. Security Authorization & Sharing Features:
     - Three Access Modes: Private, Restricted to Selected Accounts, Anyone with Link.
     - Live User Search & Multi-Select UI: Autocomplete endpoint (`/api/users/search/?q=...`) with recipient user badges.
     - Subtree Boundary Validation (`is_descendant_of`): Prevents directory traversal outside shared directory scope.
     - Protected Streaming: Nginx `X-Accel-Redirect` streaming checks account authorization before delivering media bytes.
     - Mobile Responsiveness: Off-canvas drawer menu (`☰`) and fixed floating action upload button (`+` FAB).
     - FFmpeg Video Scrubbing Strips: Low-bitrate animated WebP hover previews with NVIDIA NVENC/CUDA hardware acceleration fallback. Instant looping video preview on hover in the Drive UI.
     - Continuous Lightbox Gallery: Next/Prev buttons, keyboard arrow navigation (`←` / `→`), and responsive touch swipe gestures on mobile devices.
     - Dedicated Shared Drive Section: Left sidebar menu organizes content shared with you by user accounts, complete with deep subfolder traversal, breadcrumbs, and read-only safeguards.
     - Delta-Synced WebDAV Network Drive: Mount NitroStream directly as a desktop network drive on Windows (`net use Z: http://<ip>/webdav /user:<user> <pass>`), macOS Finder, or Linux. Direct desktop editing with automatic delta sync, quota checks, and thumbnail generation.

3. DAILY OPERATIONAL COMMANDS
--------------------------------------------------------------------------------

[ Starting the Server Stack ]
  0. Terminal 1 (huey worker):
     cd D:\projects\homeserver\homeserver
     .\venv\Scripts\activate.bat
     python manage.py run_huey

  1. Terminal 2 (Waitress Server):
     cd D:\projects\homeserver\homeserver
     .\venv\Scripts\activate.bat
     python run.py

  2. Terminal 3 (Nginx Server):
     cd C:\nginx
     start nginx

[ Useful Nginx Management Commands ]
  - Reload Nginx configuration : nginx -s reload
  - Stop Nginx gracefully       : nginx -s quit
  - Force kill all Nginx processes: taskkill /f /im nginx.exe

[ Client Access ]
  Devices on your home Wi-Fi can access the server via your laptop's IP address:
  Web Interface : http://192.168.x.x
  WebDAV Share  : http://192.168.x.x/webdav/

[ Mounting as a Network Drive on Windows ]
  Command line (PowerShell or CMD):
    net use Z: http://192.168.x.x/webdav /user:your_username your_password

  Windows File Explorer UI:
    1. Open File Explorer -> This PC -> "Map network drive".
    2. Drive Letter: Z: (or any available letter).
    3. Folder: http://192.168.x.x/webdav/
    4. Check "Connect using different credentials" and enter your NitroStream username/password.
